# LLM practice
This repo contains projects on some basic LLM concepts.

- retrieval-engine --- Minimalistic Agent + RAG implementations. Stack: Plain Python, Openrouter, without agentic framewroks, vector databases.

- langgraph-rag --- Minimalistic Agent + RAG implementations. Stack: LangGraph, LangChain, Openrouter.   

- decoder-only-transformer --- Implementation of a compact GPT-like Transformer model trained on song lyrics. Stack: Torch + Hugging Face
